Crédits et licences

3615 MESHCORE repose sur le travail des autres. Merci à toutes et à tous.

MeshCore

Le micrologiciel est MeshCore, de Scott Powell / rippleradios.com et de ses contributeurs, sous licence MIT, auquel une version dérivée ajoute l'interface Minitel dans examples/companion_radio/ui-minitel/. L'application de téléphone avec laquelle il reste compatible est l'application compagnon de MeshCore.

La police Minitel

Les caractères de tous les écrans de ce site, comme ceux des rendus photographiques, viennent de Minitel.ttf / Minitel.sfd de Frédéric Bisson (Zigazou), tirés de zigazou/minitel-canvas et placés dans le domaine public sous CC0 1.0 Universel (la licence est fournie avec la police : LICENSE-Minitel-font.txt). Elle redessine les caractères de la ROM du Minitel sur leur grille exacte de 8 × 10 points. Frédéric Bisson est aussi l'auteur de PyMinitel et de l'éditeur de pages miedit.

Les polices web du site (minitel40, minitel80 et leurs variantes pour les mosaïques disjointes) en sont reconstruites point par point par site/tools/make_webfont.py, avec les mosaïques G1 ajoutées aux points de code Unicode des sextants. Elles sont proposées sous la même dédicace CC0.

Régions : Gaulix, INSEE, geo.api.gouv.fr

  • Les noms et la hiérarchie des régions suivent les conventions de la communauté MeshCore française publiées par Gaulix : « Règles de nommage des régions et canaux MeshCore » et son Générateur de région MeshCore. La correspondance entre départements et régions a été extraite de ce générateur (la provenance est notée dans gaulix-regions.json, dans le micrologiciel).
  • Noms, préfectures et table des communes : INSEE, Code officiel géographique 2026, sous Licence Ouverte / Open Licence 2.0 (Etalab).
  • Position des mairies des préfectures et emprise des communes : geo.api.gouv.fr (API Découpage administratif), Licence Ouverte 2.0.
  • Les codes de régions et de départements ont été recoupés avec les iso-codes de Debian (ISO 3166-2) ; rien n'en est repris.

Données des émojis

La table émoji → ASCII est produite (et vérifiée par SHA-256) à partir de :

  • emoji-test.txt d'Unicode, Emoji 18.0 : chaque émoji et son nom court CLDR. © Unicode, Inc., sous Unicode License v3.
  • github/gemoji db/emoji.json : les codes courts de GitHub, MIT.
  • iamcal/emoji-data emoji.json : les codes courts de Slack, MIT.

L'interface

L'interface DIN à un transistor est celle d'arduiblog, publiée dans « Ressuscitez le Minitel » (2019). Elle est reprise telle quelle, alimentée en 3V3 et avec une résistance série ajoutée pour le XIAO ; le schéma de la page Montage est notre propre dessin.

Documentation du protocole

La gestion de la liaison a été écrite d'après les Spécifications Techniques d'Utilisation du Minitel 1B (STUM 1B), le guide d'utilisation du Minitel 2, la spécification de l'interface péri-informatique du CNET (1982), les entrées Minitel du terminfo.src de ncurses, et le code et les notes de Minitel1B_Hard, PyMinitel et iodeo/Minitel-ESP32. Ce sont des références : aucun code n'en a été repris, et ces documents ne sont pas redistribués ici.

Outils

Les outils utilisent Python, NumPy et Pillow ; les polices web sont construites avec fontTools ; le micrologiciel avec PlatformIO.
