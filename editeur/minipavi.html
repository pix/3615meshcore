3615 MESHCOREservices Minitel
Le site · Éditeur de diapositives

Le Minitel se connecte à MiniPavi et aux autres services Minitel d'aujourd'hui (3611, 3615co.de…) comme sur le réseau téléphonique : la page relie le service au Minitel par Bluetooth, sans émulateur. On tape sur le clavier du Minitel ; ENVOI, SOMMAIRE, RETOUR, SUITE… marchent comme à l'époque.

Ce navigateur n'a pas Web Bluetooth : utilisez Chrome ou Edge sur ordinateur, ou Chrome sur Android.

1 Le Minitel non connecté

Le nœud apparaît sous le nom « MeshCore-… ». La première fois, il demande un code : le Minitel l'affiche. Fermez l'application MeshCore du téléphone pendant ce temps (une seule connexion Bluetooth à la fois).

2 Le service raccroché

Les pages sont faites pour 1200 bauds : plus vite, le Minitel perd des caractères quand il efface ou fait défiler l'écran, et les animations vont trop vite. CONNEXION/FIN sur le Minitel raccroche aussi.

Journal

Bon à savoir

  • La page ne passe que par le navigateur : le service est joint en WebSocket sécurisé (wss://). Une page https ne peut pas ouvrir de ws:// (comme 3614 HACKER) ni de connexion TCP : pour ces services-là, utilisez mtl vtx sur un PC, ou ouvrez cette page en local (http://localhost).
  • Si la liaison Bluetooth se coupe, la page se reconnecte toute seule : le service reste en ligne et le Minitel garde sa page.
  • Demande un firmware récent (la session Vidéotex de mtl vtx).
