MeshCore

The firmware is MeshCore by Scott Powell / rippleradios.com and its contributors, under the MIT licence, with the Minitel user interface added in examples/companion_radio/ui-minitel/ on a fork. The phone app it stays compatible with is the MeshCore companion app.

The Minitel font

The characters on every screen of this site, and in the photo renders, come from Minitel.ttf / Minitel.sfd by Frédéric Bisson (Zigazou), from zigazou/minitel-canvas, dedicated to the public domain under CC0 1.0 Universal (licence file kept next to the font: LICENSE-Minitel-font.txt). It redraws the Minitel ROM characters on their exact 8 × 10 dot grid. Frédéric Bisson also wrote PyMinitel and the miedit page editor.

The web fonts here (minitel40, minitel80 and their "separated mosaic" variants) are rebuilt dot by dot from that font by site/tools/make_webfont.py, with the G1 mosaics added at the Unicode sextant code points. They are offered under the same CC0 dedication.

Regions: Gaulix, INSEE, geo.api.gouv.fr

  • Region names and hierarchy follow the French MeshCore community's conventions, as published by Gaulix: "Règles de nommage des régions et canaux MeshCore" and its Générateur de région MeshCore. The département-to-région mapping was extracted from that generator (its provenance is recorded in gaulix-regions.json in the firmware).
  • Names, préfectures and the commune table: INSEE, Code officiel géographique 2026, under the Licence Ouverte / Open Licence 2.0 (Etalab).
  • Préfecture town-hall positions and commune bounding boxes: geo.api.gouv.fr (API Découpage administratif), Licence Ouverte 2.0.
  • Region and département codes were cross-checked against Debian's iso-codes (ISO 3166-2); nothing from it is embedded.

Emoji data

The emoji → ASCII table is generated (checked by SHA-256) from:

  • Unicode emoji-test.txt, Emoji 18.0: every emoji and its CLDR short name. © Unicode, Inc., under the Unicode License v3.
  • github/gemoji db/emoji.json: GitHub shortcodes, MIT.
  • iamcal/emoji-data emoji.json: Slack shortcodes, MIT.

The interface

The one-transistor DIN interface is arduiblog's, from "Ressuscitez le Minitel" (2019). It is used here as published, powered at 3V3 with a series resistor added for the XIAO; the schematic on the Montage page is our own drawing of it.

Protocol references

The link layer was written from the Spécifications Techniques d'Utilisation du Minitel 1B (STUM 1B), the Minitel 2 user guide, the CNET peripheral interface specification (1982), the Minitel entries of ncurses' terminfo.src, and the code and notes of Minitel1B_Hard, PyMinitel and iodeo/Minitel-ESP32. Those are references only; no code was taken from them, and their documents are not redistributed here.

Tools

The host tools use Python, NumPy and Pillow; the web fonts are built with fontTools; the firmware with PlatformIO.
