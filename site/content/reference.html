Screen layout

RowContent
1Service line, in inverse video: 3615 MESHCORE, the page title (80 col), the unread count (blinking), BLE state, battery, local time
2–3Page title: underlined bold in 80 col, double height with a mosaic rule in 40 col
4–21Page content
22Notices, or the GUIDE help line
23Keys for this page, with key names in inverse video
24Input line: menu choice, message, or the answer to a question

40 columns use Vidéotex codes (US positioning, inverse and blink attributes, double height and size, G1 mosaics, G2 accents through SS2). 80 columns use the Mixte mode's ISO 6429 codes (CUP, ED, EL, one SGR per sequence) and the French set through SO/SI. The last cell of row 24 is never written, so the screen never scrolls.

USB command line

USB serial, 115200 baud. End each line with CR; characters are echoed; replies are indented by two spaces and end with OK (or ERR …). The MeshCore companion's own local commands (get/set of preferences and so on) work as usual; these are the ones the Minitel build adds or relies on.

Private key. get prv.key prints the secret that is the node. Anyone who has it can impersonate the node and read its direct messages. Keep it offline; never paste it into logs, chats, tickets or screenshots.

Screen dump format (v1)

  SCREEN v1 cols=<40|80> rows=25 mode=<mixte|videotex> page=<id> cellw=<8|6> cellh=10 [t=<ms>]
  ROW <r> <text_hex> <attr_hex>     r = 0..24 (row 0, the status row, is blank)
  CURSOR <r> <c> <0|1>
  OK
  • text_hex: the row's UTF-8, exactly cols characters, one per cell, with the real glyph (é). A G1 mosaic cell carries its code as an ASCII character 0x20–0x7F.
  • attr_hex: 4 hex digits per cell.
  • Double height: the character sits on the row it is written on; the cell of the row above is a blank with the continuation bit.
  • In 80 col a mosaic is drawn as an inverse blank or -/_ and double height as bold, as the terminal shows them; in 40 col bold and underline do not exist.
  • The dump is the model the firmware is drawing: rows not yet sent to the terminal already show their new content.

1blink7concealed
2underline (on a mosaic: separated)8–10foreground colour 0–7

G1 mosaic: bits 0–4 and 6 of the code are the 2 × 3 blocks top-left, top-right, middle-left, middle-right, bottom-left, bottom-right.

Host tools

Python 3, run isolated (python3 -I). The screenshot tools need numpy and Pillow; the rest is standard library. Every tool finds the XIAO as /dev/serial/by-id/*<serial>* and refuses /dev/ttyUSB* devices (on a desk with a repeater on a USB-serial adapter, opening its tty resets it). Change the serial number in the scripts for your own XIAO.

tools/screenshot/minitel_dump.py

python3 -I minitel_dump.py -o page.dump          # fetch a dump from the XIAO
python3 -I minitel_dump.py --from-file log.txt   # clean a dump out of a terminal log
python3 -I minitel_dump.py --render -- --angle   # fetch, then render

tools/screenshot/minitel_render.py

A photo-realistic render of a Minitel 2 showing the dump, computed in numpy: a ray-marched terminal on a desk, a refracting curved glass, the raster's beam spot and bandwidth, halation, reflections, depth of field and grain. Also the CRT face alone (--screen-only, about 2 s), and animated GIFs from several dumps.

python3 -I minitel_render.py page.dump                     # 1920x1440 photo
python3 -I minitel_render.py page.dump --angle --style night
python3 -I minitel_render.py page.dump --screen-only       # the tube only, 1280x960
python3 -I minitel_render.py f*.dump --frame-ms 130 -o anim.gif

tools/tour/tour.py

Walks every page in 40 and 80 columns over USB, saves each dump to gallery/dumps/ with gallery/manifest.json (page, mode, title, description), renders them and rebuilds this site. It only visits pages: every Envoi is checked against ui state and an allow-list of navigation choices first, room conversations (which log in) are skipped, and nothing that transmits is ever pressed.

python3 -I tools/tour/tour.py run                 # both modes, render, build the site
python3 -I tools/tour/tour.py run --splash-anim   # also record the welcome page animation
python3 -I tools/tour/tour.py simulate            # offline test against a fake device
python3 -I tools/tour/tour.py list                # the pages it visits

site/build.py

Builds this site into site/dist/: plain files for any web server. site/tools/make_webfont.py rebuilds the Minitel web fonts from the CC0 font.
