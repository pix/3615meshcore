    Pairing and requirements
    • Chrome or Chromium, page opened from file:// or http://localhost. On Linux, if Connect is unavailable, enable chrome://flags/#enable-experimental-web-platform-features.
    • The companion needs bonding with a PIN that the Minitel displays. On Linux, pair it first: bluetoothctl, scan on, pair <MAC>, enter the PIN shown on the Minitel, then trust <MAC>.
    • Only one central can be connected at a time: close the MeshCore phone app (or mtl) first.

    Slide designer
    
  
    Extra welcome-page slides for the 3615 MESHCORE companion. Each slide may have a 40 col (Vidéotex) version, an 80 col (Mixte) version, or both; the Minitel plays the one for its current mode and skips the slide otherwise.
    
  
    Keyboard (click the screen first)
    
  
      
    
    • Type to write at the cursor with the pen's attributes; arrows move (Shift extends a selection), Enter goes to the next line, Backspace / Delete erase.
      • 
    
    • Ctrl+Z / Ctrl+Y undo / redo, Ctrl+A select all, Ctrl+C / X / V copy, cut, paste (cells, or plain text from elsewhere), Esc drops the selection, Ctrl+S saves the project.
      • 
  
    
  
    Mouse
    
  
      
    
    • Text: click places the cursor, drag selects. Fill / Apply pen / Clear work on the selection, or on the whole screen when nothing is selected.
      • 
    
    • Draw / Erase: mosaic pixels, 2×3 per cell (40 col only). A cell has one colour: drawing in it gives it the pen colour. Right button erases while drawing.
      • 
    
    • Paint applies inverse / blink / colour (80 col: bold, underline too) to cells; Pick takes them from a cell.
      • 
  
    
  
    Minitel limits
    
  
      
    
    • Double height is drawn on the cursor row and covers the row above; not on row 1.
      • 
    
    • No accented capitals (É becomes E); 80 col has only à é è ù ç £ § ° among the accents, others lose the accent.
      • 
    
    • The last cell of row 24 is never written (it would scroll the screen in Mixte).
      • 
    
    • Each version is at most 12288 bytes once encoded.
